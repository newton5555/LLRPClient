# LLRPReaderUI_WPF UI 操作手册

## 1. 概述
### 1.1 软件简介
LLRPReaderUI_WPF 是一款基于 LLRP 协议的专业 RFID 读写器控制与测试软件，通过 LLRPSdk 与读写器建立通信，支持标准 LLRP 协议下的设备配置、标签盘点、内存读写及高级安全操作。

### 1.2 运行环境
- 操作系统：Windows 10 / Windows 11
- 运行时：.NET 9.0 Runtime
- 网络：需与读写器处于同一网段或路由可达

### 1.3 功能概览
| 功能模块 | 说明 |
| --- | --- |
| 设备连接 | IP:Port 连接，自动解析设备能力集（型号、固件、天线、射频参数等） |
| 参数配置 | 心跳保活、Session、标签总体估计、RF Mode、跳频表、状态感知盘点、断线保留事件/报告、天线独立配置、恢复出厂 |
| GPIO 配置 | GPI 使能及实时状态监控，GPO 目标电平设置与应用 |
| 盘点配置 | 自动启停逻辑、双重标签过滤、选择性过滤器、报告模式（含 BatchAfterStop）及字段选择、附加数据配置 |
| 盘点操作 | 实时寻卡、盘点时长、数据统计（报告数/标签数/独立数）、列显隐控制、手动缓存拉取 |
| 读写操作 | 按 EPC/TID 匹配标签，支持四个内存区读写，可选 BlockWrite，5s 超时保护 |
| 高级操作 | Lock/Unlock/Permalock/Permaunlock、Kill、BlockErase，5s 超时保护 |
| 日志 | 三类日志（操作、LLRP 消息、原始帧），批量 UI 刷新 |
| LLRP 消息 | SQLite 历史消息库查询，多维筛选（日期/方向/类型/设备ID/文本），消息树解析与导出 |

## 2. 快速开始
### 2.1 连接设备
1. 在「设备连接」页面，输入读写器 IP 或 IP:Port（支持最近 3 条历史记录快速选择）。
2. 点击「连接」，连接成功后底部状态栏显示设备连接状态及 MAC 地址，下方加载设备能力集。
3. 若读写器当时正在盘点，软件会自动停止盘点后再初始化。

### 2.2 一键盘点
1. 点击左侧导航进入「盘点操作」。
2. 点击「开始寻卡」。
3. 列表实时展示扫描到的标签，上方显示总报告数、总标签数与独立标签数。

## 3. 功能模块详解
### 3.1 设备连接与能力查看
连接成功后，系统展示完整的 FeatureSet：
- 核心信息：型号(ModelNumber)、读写器型号(ReaderModel)、制造商编号（带厂商名称）、固件版本、天线/GPI/GPO 数量。
- 协议能力：通信标准(CommunicationsStandard)、国家代码（带国家名）、最大操作序列数/每序列操作数、标签访问是否可用、过滤是否可用及最大过滤器数。
- 内存操作：是否支持多字块写(IsMultiwordBlockWriteAvailable)和块擦除(IsMultiwordBlockEraseAvailable)。
- 射频能力：是否为跳频区域(IsHoppingRegion)、发射功率等级数、接收灵敏度等级数、频率点数、射频模式数。

Keepalive 超时保护：若连接后读写器长时间无心跳响应，软件将自动断开并提示超时。

### 3.2 参数配置（Settings）
三个核心操作按钮：获取配置、保存配置、恢复出厂默认。
- 心跳保活：启用/禁用 Keepalive 及设置心跳间隔(ms)。
- 射频模式与频率：
  - RF Mode：采用 Pn 前缀和 mode id（如 P0-0、P1-2），详细展示 M 值、TARI 等参数。
  - 跳频管理：选择 HopTable ID，跳频区域（FCC/ETSI）下按表定义频率序列切换，单个信道索引通常无效。
  - 信道索引：配置 Channel Index 并显示当前频点（非跳频区域可定位固定频率）。
- 盘点策略：
  - Session：支持 0、1、2、3 四种会话模式。
  - 标签总体估计(TagPopulationEstimate)：影响盘点算法效率。
  - 状态感知(State-Aware)：设备支持时可用，配置 Target(A/B)及搜索模式(SL/Not_SL)。
- 断线策略：断开后保持事件/报告（Hold Reports On Disconnect）。
- 天线管理：按实际天线数量动态生成配置项，独立配置使能开关、发射功率(TxPower dBm)、接收灵敏度(RxSensitivity dBm)。
- 事件通知：显示 ReaderEventNotificationSpec 各事件类型启停状态。

### 3.3 GPIO 配置
- GPI：按端口显示使能开关与当前电平状态（高/低/未知），修改使能后点击「保存 GPI 配置」下发。
- GPO：为每个输出端口设定目标电平（高/低），点击「应用 GPO」批量下发并刷新实际状态。

### 3.4 盘点配置（Inventory Config）
两个核心操作按钮：读取配置、保存配置。
- 启停控制：
  - 启动模式：手动(None)、立即(Immediate)、GPI 触发、周期性(Periodic)；周期性可配置首次启动延迟/UTC 定时、循环周期。
- 停止模式：手动(None)、持续时长(Duration)、GPI 触发、GPI 超时(Timeout=0 表示不限)。
- 标签过滤(Filters)：
  - 过滤模式：无过滤、单过滤、双过滤。
  - 标准过滤：双重过滤器，按内存区(EPC/TID/User/Reserved)、位偏移、位数、掩码、过滤动作(Match/NonMatch)配置。
  - 选择性过滤器(Tag Select Filters)：动态增删多组 Select 规则，含内存区、位偏移、位数、掩码、匹配/非匹配动作。
- 报告配置：
  - 报告模式：Individual（每次盘点即报告）、WaitForQuery（缓存至手动拉取）、BatchAfterStop（停止后统一上报）。
  - 报告字段：自由勾选 PC、CRC、首次/末次读取时间、天线编号、信道、Peak RSSI、读取次数。
- 附加数据：开启后同步读取指定内存区数据，配置内存区（默认 TID）、起始字地址、字数（默认 6）、访问密码。

### 3.5 盘点操作
- 操作按钮：开始寻卡、停止寻卡、清空数据、手动拉缓存。
- 统计面板：实时更新总报告数、总标签数（含重复）、独立标签数与盘点时长。
- 手动拉缓存：仅报告模式为 WaitForQuery 时可用。
- 列显示控制：与盘点配置报告字段勾选项实时同步。
- 标签数据字段：接收时间、EPC、天线端口、信道频率(MHz)、Peak RSSI(dBm)、读取次数、PC、CRC、首次/末次读取时间(UTC)、附加数据。
- 容量限制：列表最多显示 500 行，超出自动移除最旧记录。

### 3.6 读写操作
- 目标匹配：通过 EPC（bit 32 开始）或 TID（bit 0 开始）锁定单张标签。
- 内存区：User、TID、Reserved、EPC。
- 读取：指定字指针和字数读取。
- 写入：输入十六进制数据，长度须为 4 的倍数（整字）。
- BlockWrite：设备支持时可勾选启用。
- 访问密码：32 位十六进制（默认 00000000）。
- 5 秒超时保护：操作内置 5000ms 超时，超时自动提示并释放 UI。
- 附加数据恢复：操作前自动停止盘点并保存附加数据状态，完成后自动恢复。

### 3.7 高级标签操作
- 目标匹配：同读写操作，通过 EPC/TID 锁定标签。
- 核心功能：
  - Lock：对 KillPassword、AccessPassword、EPC、TID、User 区执行 Lock/Unlock/Permalock/Permaunlock。
  - Kill：通过 32 位销毁密码永久失效标签，密码为 8 位十六进制字符。
  - Block Erase：块擦除指定内存区，设备支持时按钮可用。
- 自动化逻辑：5 秒超时保护；操作前保存附加数据状态，完成后停止、清除操作序列并恢复。

### 3.8 日志系统
- 日志类型：操作日志、LLRP 消息日志、原始报文日志。
- 显示控制：每类日志可独立开关。
- 批量刷新：200ms 间隔批量更新 UI，避免卡顿。
- 容量限制：每类日志最多 500 条。

### 3.9 LLRP 消息浏览
从 SQLite 数据库（llrp_rawframes.db）加载历史 LLRP 原始消息帧。
- 筛选功能：时间段、方向(All/RX/TX)、消息类型、设备 ID、文本搜索、一键清除筛选。
- 消息解析：选中记录后右侧展示消息树（完整 LLRP 消息层级）、原始 Hex 报文。
- 操作：刷新（加载最近 5000 条）、导出（解析树为 .txt，默认保存到程序运行目录）、清空（数据库所有记录）。

### 3.10 底部状态栏
常驻展示实时信息：设备状态、盘点状态、天线状态、GPI 状态、GPO 状态、设备 MAC 地址；支持点击「刷新状态」手动查询。

### 3.11 主题与语言
- 支持中文/English 界面切换。
- 支持明暗主题切换。
- 切换后导航菜单、状态文本、操作提示实时更新。

## 4. 常见问题（FAQ）
**Q：为什么在跳频模式下设置信道索引无效？**
A：跳频模式下读写器按跳频表循环工作，单个信道索引通常被忽略或无效。

**Q：高级操作或读写操作提示「Timeout」？**
A：操作内置 5 秒超时，确认标签在天线近场，且未开启过强标签过滤。

**Q：盘点列表中「接收时间」和「FirstSeenTime」的区别？**
A：接收时间是 PC 端收到报告的本地时间；FirstSeenTime 是读写器检测到标签的 UTC 时间戳，精度更高。

**Q：手动拉缓存按钮灰色不可用？**
A：仅盘点配置报告模式设为 WaitForQuery 时可用，先切换报告模式。

**Q：BlockWrite / BlockErase 按钮不可用？**
A：需读写器硬件支持，连接后软件自动检测，不支持则按钮禁用。
