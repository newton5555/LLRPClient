# LLRPReaderUI_WPF UI 操作手册

## 1. 概述

### 1.1 软件简介

LLRPReaderUI_WPF 是一款基于 LLRP 协议的 RFID 读写器控制软件，提供设备连接、标签盘点、数据读写、GPIO 控制等功能。软件采用 WPF 框架开发，界面简洁直观，支持多种 LLRP 兼容读写器。

### 1.2 运行环境

- **操作系统**：Windows 10 / Windows 11
- **运行时**：.NET 8.0 Runtime
- **网络**：需能访问读写器 IP 地址

### 1.3 功能概览

| 功能模块 | 说明 |
|---------|------|
| 设备连接 | 连接/断开读写器，查看设备能力信息 |
| 参数配置 | 心跳、Session、功率、天线等参数设置 |
| GPIO配置 | GPI/GPO 端口状态监控与控制 |
| 盘点配置 | 自动启停、标签过滤、报告模式配置 |
| 盘点操作 | 开始/停止寻卡，查看标签数据 |
| 读写操作 | 读取/写入标签内存数据 |
| 高级标签操作 | 锁定、销毁、块擦除等操作 |
| 日志 | 查看操作日志和 LLRP 消息 |
| 历史LLRP消息 | 查看、筛选、导出历史消息记录 |

## 2. 快速开始

### 2.1 连接设备

1. 启动软件后，默认进入「设备连接」页面
2. 在地址栏输入读写器 IP 地址（如 `192.168.1.100`）
3. 点击「连接」按钮
4. 连接成功后，页面下方显示设备能力信息

> **提示**：支持指定端口，格式为 `IP:端口`，如 `192.168.1.100:5084`

### 2.2 开始寻卡

1. 连接设备后，点击左侧导航「盘点操作」
2. 点击「开始寻卡」按钮
3. 标签数据将实时显示在列表中
4. 点击「停止寻卡」结束盘点

## 3. 功能模块详解

### 3.1 设备连接

![设备连接页面]

**功能说明**：

| 功能 | 操作 |
|-----|------|
| 输入地址 | 在下拉框输入 IP 地址或主机名 |
| 连接设备 | 点击「连接」按钮 |
| 断开设备 | 点击「断开」按钮 |
| 查看历史 | 下拉框显示最近连接的 3 个地址 |

**设备能力信息**：

连接成功后显示以下信息：
- 型号编号 (ModelNumber)
- 读写器型号 (ReaderModel)
- 制造商编号 (DeviceManufacturerNumber)
- 固件版本 (FirmwareVersion)
- 天线数量 (AntennaCount)
- GPI/GPO 数量
- 发射功率列表 (TxPowers)
- 接收灵敏度列表 (RxSensitivities)
- 射频模式列表 (RfModes)

---

### 3.2 参数配置

**心跳配置**：
- **启用心跳**：是否开启 TCP 心跳保活
- **心跳间隔**：心跳发送间隔（毫秒）

**盘点参数**：
- **Session**：盘点会话模式（0-3）
- **标签数量估算**：预期盘点区域内的标签数量

**发射功率**：
- 选择各天线的发射功率值

**接收灵敏度**：
- 选择各天线的接收灵敏度值

**天线配置**：
- 勾选启用的天线端口
- 为每个天线设置独立功率

**事件通知**：
- 配置需要启用的事件通知类型

**操作按钮**：
| 按钮 | 功能 |
|-----|------|
| 获取参数 | 从设备读取当前配置 |
| 应用参数 | 将配置写入设备 |
| 重置为默认 | 恢复出厂默认配置 |

### 3.3 GPIO 配置

**GPI（输入端口）**：
| 列 | 说明 |
|----|------|
| 端口号 | GPI 端口编号 |
| 启用 | 是否启用该端口 |
| 当前状态 | 高/低电平状态 |

**GPO（输出端口）**：
| 列 | 说明 |
|----|------|
| 端口号 | GPO 端口编号 |
| 目标状态 | 设置输出状态（高/低） |

**操作步骤**：
1. 点击「查询 GPIO」获取当前状态
2. 修改 GPO 目标状态
3. 点击「应用 GPO」写入设置

**标签过滤配置**：

**报告配置**：
| 参数 | 说明 |
|-----|------|
| 报告模式 | 单次/连续 |

### 3.5 盘点操作

**主要操作**：

| 按钮 | 功能 |
|-----|------|
| 开始寻卡 | 启动盘点 |
| 停止寻卡 | 停止盘点 |
| 手动拉缓存 | 手动拉取缓存的标签报告 |

**标签列表字段**：

| 字段 | 说明 |
|-----|------|
| 接收时间 | 标签被读取的时间 |
| EPC | 电子产品码 |
| 天线 | 读取该标签的天线端口 |
| 频率(MHz) | 射频频率 |

| 次数 | 该标签被读取次数 |
| PC | 协议控制字 |
| CRC | 循环冗余校验 |
| FirstTimestamp | 首次读取时间 |
| LastTimestamp | 最后读取时间 |
| 附加数据 | TID 或自定义数据 |

**列显示控制**：
右键列表标题栏或通过配置选择显示/隐藏列。

**上下文菜单**：
- 复制 EPC
- 复制附加数据
- 复制选中行

**目标标签设置**：

| 参数 | 说明 |
|-----|------|
| 目标标签内存区 | EPC 或 TID |
| 目标标签数据 | 用于匹配标签的数据（十六进制） |

**读写参数**：

| 参数 | 说明 |
|-----|------|
| 内存区 | User/TID/Reserved/EPC |
| 字指针 | 起始字地址 |

| 访问密码 | 32位访问密码（十六进制） |

**操作按钮**：

| 按钮 | 功能 |
|-----|------|
| 读取 | 执行读取操作 |
| 写入 | 执行写入操作 |

**操作流程**：
1. 输入目标标签数据（如 EPC）
2. 选择内存区
3. 设置字指针和字数
4. 点击「读取」或「写入」

## 4. 常见问题

### Q1: 连接失败怎么办？

1. 检查读写器是否开机
2. 确认电脑与读写器网络连通（ping 测试）
3. 确认 LLRP 端口正确（默认 5084）
4. 检查防火墙是否放行

### Q2: 盘点不到标签？

1. 确认天线已正确连接
2. 检查天线是否在「参数配置」中启用
3. 尝试调高发射功率
4. 确认标签在读取范围内

### Q3: 读写操作失败？

1. 确认目标标签数据正确
2. 检查访问密码是否正确
3. 确认标签支持该内存区操作
4. 查看日志了解详细错误信息

### Q4: 数据存储位置？

- 配置文件：`%LocalAppData%\LLRPReaderUI_WPF\`
- 日志数据库：`%LocalAppData%\LLRPReaderUI_WPF\llrp_rawframes.db`
